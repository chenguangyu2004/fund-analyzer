# 基金分析App — AI多因子透视诊断

基于 Python + Flask 的基金智能分析工具，集成 **AI多因子透视诊断模型**，对基金进行五维度量化评分 + DeepSeek AI 深度解读。

**版本**: v7.1.0 (2026-05-30)

---

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置 AI（可选，推荐）
echo DEEPSEEK_API_KEY=sk-your-key > .env

# 3. 启动
python app.py
```

浏览器访问 **http://127.0.0.1:5000**

> 无 API Key 也能使用基础分析（净值、盈亏、持仓、K线），AI 功能需要 [DeepSeek 密钥](https://platform.deepseek.com/)。

## 核心功能

### AI 多因子透视诊断

基于《AI多因子透视诊断模型规格书 v2.0》，五模型并行打分 + 市场环境动态权重 + AI 综合解读：

| 模型 | 权重 | 核心问题 | 关键指标 |
|:---|:---:|:---|:---|
| **M1 个股质量** | 25% | 买的是不是好公司？ | ROE、毛利率、净利增速、OCF/NI、负债率 |
| **M2 估值性价比** | 25% | 好公司现在贵不贵？ | PE分位数、PB分位数、PEG、股息率 |
| **M3 舆情动量** | 20% | 市场认可这些公司吗？ | 新闻情感、分析师评级、资金流向 |
| **M4 行业景气** | 15% | 赛道顺风还是逆风？ | 行业景气度、政策支持、宏观匹配 |
| **M5 经理行为** | 15% | 管钱的人靠谱吗？ | 风格稳定性、调仓质量、业绩可持续 |

权重按市场环境**动态调整**（正常/牛市/熊市/震荡市/高不确定性 5 种模式）。

**工作流程**：获取基金数据 → 20只重仓股并发获取 → 五模型定量打分 → 市场环境识别 → 动态权重 → AI 综合解读

### 基金基础分析

- 基金基本信息：名称、净值、基金经理、规模、类型
- 盈亏计算：总盈亏、当日盈亏、持仓成本 vs 当前价值
- 历史净值走势 + 沪深300基准对比
- 前十大持仓：实时价格、涨跌幅、行业分布
- 实时估算净值：基于持仓股票价格计算（交易时段）

### 个股详情页

- 实时行情（A股/港股/北交所全覆盖）
- **K线图**（日K/周K/月K，支持A股+港股）
- 财务数据（ROE、EPS、营收、净利润、负债率）
- **个股新闻**（A股：新浪个股页+东方财富公告；港股：新浪个股页+腾讯快讯）
- **行业龙头股**（同行业龙头 + 实时涨跌，JSON数据+AI自动保鲜）

### AI 对话问答

- 单基金深度问答
- 跨基金对比分析
- 投资组合诊断

## API 端点

| 端点 | 方法 | 说明 |
|:---|:---|:---|
| `/` | GET | 基金分析主页 |
| `/stock` | GET | 股票详情页 |
| `/api/analyze` | POST | 基金基础分析（信息、盈亏、持仓、历史） |
| `/api/ai-analyze` | POST | **AI 多因子透视诊断**（五模型评分 + AI 解读） |
| `/api/ai-chat` | POST | AI 对话问答（单基金/跨基金/组合） |
| `/api/stock/<code>` | GET | 股票详情（行情、新闻、龙头、财务） |
| `/api/stock/<code>/kline` | GET | 股票K线数据（日/周/月） |
| `/api/market-overview` | GET | 市场概况（四大指数 + 财经新闻） |
| `/api/check-api-key` | GET | 检查 API Key 是否配置 |
| `/api/fund/<code>/benchmark` | GET | 基金净值 + 沪深300 基准对比 |
| `/api/fund/<code>/risk-metrics` | GET | 风险指标（夏普/回撤/波动率） |
| `/api/fund/<code>/fees` | GET | 基金费率结构 |
| `/api/fund/<code>/strategy-analysis` | GET | 量化策略（长期稳定性/下跌预测/上涨预测） |
| `/api/portfolio-analyze` | POST | 投资组合 AI 分析 |

## 配置说明

所有参数通过 `.env` 文件或环境变量配置：

| 变量 | 默认值 | 说明 |
|:---|:---|:---|
| `DEEPSEEK_API_KEY` | *(空)* | DeepSeek API 密钥 |
| `DEEPSEEK_MODEL` | `deepseek-v4-pro` | AI 模型选择 |
| `FLASK_HOST` | `127.0.0.1` | 服务器监听地址 |
| `FLASK_PORT` | `5000` | 服务器端口 |
| `LOG_LEVEL` | `INFO` | 日志级别 |
| `AI_MAX_TOKENS` | `8192` | AI 最大输出长度 |
| `REQUEST_TIMEOUT_AI` | `120` | AI 请求超时(秒) |

详见 `.env.example`。

## 数据维护

行业龙头数据通过 `data/industry_leaders.json` 管理，**每次启动时后台自动用 AI 扫描变化并追加新龙头**（每天一次，需 API Key）。

也可手动编辑 JSON 文件，重启后生效：

```json
{
  "互联网": [
    {"code": "00700", "name": "腾讯控股"},
    {"code": "09988", "name": "阿里巴巴"}
  ]
}
```

同样可编辑 `data/industry_benchmarks.json` 更新行业基准数据（ROE中位数/PE中位数等）。

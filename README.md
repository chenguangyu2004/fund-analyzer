# 基金分析App — AI多因子透视诊断

基于Python开发的基金分析工具，集成 **AI多因子透视诊断模型** 对基金进行五维度量化评分+AI深度解读。

**版本**: v7.0.0 (2026-05-23)

## 快速开始

## ✨ 核心功能

### AI多因子透视诊断 v7.0

基于《AI多因子透视诊断模型规格书 v2.0》，对基金进行五模型并行打分+动态权重+AI综合解读：

| 模型 | 权重 | 核心问题 |
|:---|:---:|:---|
| **M1 个股质量** | 25% | 基金买的是不是好公司？ROE、毛利率、净利增速、现金流、负债率 |
| **M2 估值性价比** | 25% | 好公司现在贵不贵？PE分位数、PB分位数、PEG、股息率 |
| **M3 舆情动量** | 20% | 市场认可这些公司吗？新闻情感、分析师评级、调研热度、资金流向 |
| **M4 行业景气** | 15% | 赛道顺风还是逆风？行业景气度、政策支持、宏观匹配度 |
| **M5 经理行为** | 15% | 管钱的人靠谱吗？风格稳定性、调仓质量、言行一致性、业绩可持续 |

**工作流程**：获取基金数据 → 获取20只重仓股详情(并发) → 五模型定量打分 → 市场环境识别 → 动态权重调整 → DeepSeek AI综合解读

### 基金基础分析

- 基金基本信息：名称、净值、基金经理、规模、类型
- 盈亏计算：总盈亏、当日盈亏、持仓成本 vs 当前价值
- 历史净值走势：近30天折线图
- 前十大持仓：实时价格、涨跌幅、行业分布
- 实时估算净值：基于持仓股票价格计算（交易时段）

### 多市场持仓价格

- A股（上证/深证/北交所）、港股全覆盖
- 自动识别股票代码所属市场
- 批量并发获取，速度快

### 数据优化

- 股票数据并发获取（5线程），大幅提速
- 市场环境数据并发获取（4数据源并行）
- QDII基金兼容（pingzhongdata兜底）

## API 端点

| 端点 | 方法 | 说明 |
|:---|:---|:---|
| `/` | GET | 基金分析主页 |

| `/api/market-overview` | GET | 市场概况 |

## 使用说明

### 基本流程

1. 输入6位基金代码（如 `000001`）
2. 输入持仓成本和份额
3. 点击"分析基金"
4. 查看基金基本信息、盈亏、持仓、历史走势
5. 点击 AI分析区的 **"开始分析"** 按钮
6. 等待30-60秒获取多因子诊断结果：
   - 综合评分（0-100分）+ 等级
   - 五模型评分条形图（含动态权重）
   - AI综合诊断摘要
   - 详细分析（分M1-M5段落）
   - 核心持仓诊断表（质量分+估值分+诊断评语）
   - 风险点列表
   - 操作建议

### AI 功能说明

- 需要配置 DeepSeek API Key（免费额度即可使用）
- 未配置时仍可使用基础基金分析
- AI分析约需30-60秒（取决于持仓数量和市场数据）
- 分析结果结合定量评分和AI定性解读
